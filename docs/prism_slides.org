* What we are doing

- Quant psych: repeated measurements per person over time —
  longitudinal data
- Missing data is the norm: dropout, skipped waves
- Most analyses need a completed dataset
- prism: complete the data so its structure matches the model

* FIML estimates — but returns no dataset

- FIML fits the model under MAR — but returns no completed dataset
- *Unconstrained imputation is not desirable:* =lavPredict= shrinks
  variance 40–60%, =MICE= and =missForest= drift the covariance — it
  needs a constraint

* The idea — project onto the FIML structure

- FIML gives the target $(\hat{\mu}, \hat{\Sigma})$
- prism moves the imputed scatter onto that target — observed cells
  untouched

* What prism takes in

- *In:* incomplete data + =lavaan= model + initial imputation $X^{(0)}$
  (e.g. =missForest=)
- *Out:* completed data matching the FIML target — only missing cells move
- *Fallback:* no initial imputation? column means are used — worse
  values, same structure

* The objective — one equation, two forces

- Move only the missing cells to minimize

  $$ f(X) = \frac{1}{2N_{\mathrm{mis}}} \lVert M \odot (X - X^{(0)}) \rVert_{F}^{2} + \frac{\lambda_{\Sigma}}{2p^{2}} \lVert \operatorname{Cov}(X) - \Sigma_{\mathrm{FIML}} \rVert_{F}^{2} $$

- *First term* — stay close to the initial imputation
- *Second term* — pull the covariance to the FIML target
- $\lambda_{\Sigma}$ balances the two

* Results

- GCM + SEM; $N$ 100–5000; 5–30% missing; MAR/MNAR — distance to the
  true covariance
- GCM, Normal, MAR: FIML 1.35 · =lavPredict= 4.68 · prism 6.66 ·
  =MICE= 6.70 · =missForest= 6.74
- GCM, Normal, MNAR: FIML 3.48 · prism 4.00 · =missForest= 4.08 ·
  =MICE= 4.40 · =lavPredict= 7.18
- SEM, Normal: FIML 0.30 · =MICE= 0.44 · prism 0.61 · =missForest= 0.62 ·
  =lavPredict= 1.45 — prism beats its starting imputation in every
  setting

* Multiple imputation — and the honest caveat

- =prism_mi=: proper multiple imputation — fresh initializations +
  parameter draws
- prism completes data for everything FIML cannot feed; refitting on
  prism data beats the initial imputation — still short of FIML

* Take-aways

- prism projects an initial imputation onto the FIML-implied
  $(\mu, \Sigma)$ — best completed-data covariance recovery in the grid
